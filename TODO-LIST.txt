AgentFlow Framework Analysis and Improvement Plan
=================================================

## Repository Summary
AgentFlow is a Go-based template engine for AI prompt engineering that:
- Provides a custom .af syntax for dynamic prompt templates
- Supports type-safe variable interpolation (string, int, bool, float32, float64)
- Includes conditional logic blocks
- Generates efficient Go code from templates
- Offers CLI tools and LSP support for IDE integration

## Critical Issues Identified
1. **CRITICAL: Tokenization and Parsing Bugs** ⚠️
   - Multiple test failures in pkg/token and pkg/ast
   - Tokenizer splits text into individual words instead of preserving text blocks
   - AST parser includes ".title" directive in title names
   - These bugs break core functionality
